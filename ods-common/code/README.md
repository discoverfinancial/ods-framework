# ODS Common Package (ods-common)

The Operational Data Store (ODS) common package is a required dependency for ods-framework. It contains interfaces for ODS data models (in the models directory) and document states (in the states directory).

## Utils

There are two utility classes included that assist with using and rendering ODS content.  The odsUtils can be used on server and browser, while the odsUi defines the browser's AppContext interface.
